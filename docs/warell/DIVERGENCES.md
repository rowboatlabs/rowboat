# Divergences avec l'upstream

Chaque fichier **venu de `rowboatlabs/rowboat`** que Warell modifie a une ligne ici : ce qu'on y change, pourquoi, depuis quand. Les fichiers créés par Warell n'y figurent pas, ils ne peuvent pas entrer en conflit. La méthode est dans [`UPSTREAM.md`](./UPSTREAM.md).

Une ligne s'ajoute dans le même commit que la modification, et disparaît dans le même commit que son retrait.
