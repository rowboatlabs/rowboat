Member card on mobile, Discord-style

Tap a name or avatar in a space and a card slides up: who they are, whether they're around, their role here, and one tap to message them. Today that tap does nothing on the phone. Four frames: a person and an agent, light and dark.

Dashed blue: the tap target. Dashed orange: needs data the server doesn't send today.

How it would go into the app

  1. One component, components/member-card.tsx, on the existing bottom-sheet.tsx. Takes a SpaceMember; no new server calls for the "Have" rows.
  2. Open it from the avatar and name in space-message.tsx (stream and threads), the Members screen rows, and mention chips. Reading still doesn't navigate: only the avatar/name are targets, the message body isn't.
  3. Owner actions (Edit, Rename) reuse spaces/agent.tsx; the ⋯ menu holds Copy link (/u/<id>), Report, and admin role changes.
  4. Desktop parity: the renderer already has MemberProfilePopover (components/spaces/atoms.tsx); this card is the phone's version of it, so a later PR can align the two.
  5. Later, server-side: a person's About field and "spaces you share" are Harbor changes and would be separate PRs.

Recommendation: ship the card with the "Have" rows only (frames 2 and 4 are fully buildable today; 1 and 3 minus the orange panels), then decide on About and shared spaces after review.
