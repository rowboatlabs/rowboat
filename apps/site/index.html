22 April 2025

Show HNRowboat – Open-source IDE for multi-agent systems

161 points51 comments

What it was

Our first public release. An AI-assisted IDE for building teams of agents: start with one agent, then add more agents and MCP tools, guided by a copilot that edits agent instructions with code-style diffs. The pitch: "Rowboat is to AI agents what Cursor is to code."

How it was received

  • The top thread came from Simon Willison, who pushed back on our premise: "I don't buy that premise (yet)", that multi-agent systems beat a single agent. It started a 14-reply debate.
  • People asked for a native app instead of another web app, and asked whether it counts as an IDE without a text editor.
  • Builders who had tried node-based agent builders were enthusiastic: "this checks all the boxes for me."

16 September 2025

Launch HNRowboat (YC S24) – Open-source IDE for multi-agent systems

66 points28 comments

What it was

Our official YC launch. It added a hosted cloud version, built-in integrations with hundreds of tools (Gmail, GitHub, Slack), RAG over documents and URLs, and triggers that start assistants from outside events. It came with $10 of free usage, and paid plans started at $20 a month.

How it was received

  • The hard questions were about positioning: "why would I use this over n8n?", and how it compares with Relevance AI.
  • We took a clear position in the thread: flowchart-style agent builders won't scale as models get better at reasoning. Building agents should feel like onboarding a new teammate.
  • One commenter said the playful UI looked like it was made for children. The feedback was blunt and fair.

18 November 2025

Show HNRowboatX – open-source Claude Code for everyday automations

131 points42 comments

What it was

A turn toward the terminal. RowboatX is a CLI modeled on Claude Code that creates and supervises background agents for work that isn't coding. Its state lives in the file system (instructions, memory and logs are plain files you can grep), a supervisor agent drives everything with Unix tools, and agents pause to ask a person for input. Install with npx @rowboatlabs/rowboatx.

How it was received

  • The biggest thread (21 replies) was about pricing, not features: people stay on Claude Code because of its fixed-price plan, and they worry that API-key tools cost more once they use them for real.
  • Commenters agreed with the premise: "I'm increasingly seeing code-adjacent people who are using coding agents for non-coding things." They compared it with Block's Goose and the Cline CLI.
  • People asked whether it could run local LLMs. It can.

10 February 2026

Show HNRowboat – AI coworker that turns your work into a knowledge graph (OSS)

205 points56 commentsFront page · #1 on GitHub Trending

What it was

The same idea, explained better. Rowboat is a local-first app that turns email, meetings and voice memos into a living knowledge graph of plain Markdown with backlinks. On top of it sits an assistant with shell access and MCP that uses the graph to do real work, such as "Build me a deck about our next quarter roadmap."

How it was received

  • This time the questions were about how it works, a sign that people took it seriously. How do we handle growing context and contradictory facts? How do we merge duplicate entities?
  • People asked for email and calendar providers other than Google (IMAP, JMAP, CalDAV), and the request came up again at every later launch.
  • "This is a product that just makes sense to me. Well done on picking a great problem to solve and communicating it so well."

What came after on X

Two months later, Andrej Karpathy described the "LLM wiki" idea, and Rowboat became one of the projects people pointed to.

Show HNRowboat – Open-source, local-first alternative to Claude Desktop

219 points99 commentsOur biggest launch

What it was

Rowboat as a full work app rather than a chat window. It added work surfaces, where the assistant helps inside the workflow itself: an email client that writes drafts in your voice, a local meeting notetaker, an isolated browser, parallel Claude Code and Codex sessions over ACP, and Obsidian-style notes. You can also build your own apps inside Rowboat. The idea came from our support-AI days: "it's not enough for the AI to be right, the help has to show up where the work is happening."

How it was received

  • The most-replied thread (20 replies) asked for a tool where "more than one person" can take part in the conversation and take turns steering it. Two months later, that is what we shipped.
  • There was real criticism. One commenter warned about an "asymmetry of effort": AI that gives everyone more to read. Another challenged the "local-first" label because transcription, voice and analytics still use cloud services.
  • The IMAP request came up again, and long-time users told us they point Claude at their Rowboat folder as a context store.

What six launches taught us

What we learned from 276 HN comments.

Read the top thread

The most-replied comment on each launch named our next problem: whether multi-agent systems are worth it, why use this over n8n, pricing, and finally multiplayer. Each time, we built what that thread asked about.

A flop is information

Our January post got 7 points. Three weeks later the same product, explained more clearly, got 205 points and reached #1 on GitHub Trending.

Plain files win trust

Markdown on disk, grep-able runs, and Apache-2.0 came up as reasons people tried Rowboat, and "is it really local?" is a question we have to answer honestly.

The same request at every launch

IMAP and calendars beyond Google came up at every launch from February on. When a request keeps coming back, it belongs on the roadmap.
