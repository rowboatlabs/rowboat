# Pi logo

- `logo.png`: `https://pi.dev/logo.svg` (the primary three-colour logo)
- `logo-dark.png`: the same image. The press kit describes the primary logo as a "Vector logo for light/dark usage", and its colours read on both backgrounds.

The file comes from the Pi press kit, <https://pi.dev/press-kit>, downloaded on 2026-09-30. This is the Pi coding agent by Earendil Inc. (repository `github.com/earendil-works/pi`), the one Replicas links to from its Pi docs. The press kit also offers a monochrome square badge (`/favicon.svg`), which was not used. The 800 × 800 SVG was rendered to 128 × 128 with sharp 0.35.3 (libvips 8.18.3, librsvg 2.62.90), keeping its transparent background, with no other change. The repository is MIT-licensed; the mark belongs to Earendil Inc. and is used here only to identify Pi.
