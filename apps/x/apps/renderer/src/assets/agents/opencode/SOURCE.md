# OpenCode logo

- `logo.png`: `packages/console/app/src/asset/brand/opencode-logo-light-square.svg` (the dark mark, for light backgrounds)
- `logo-dark.png`: `packages/console/app/src/asset/brand/opencode-logo-dark-square.svg` (the light mark, for dark backgrounds)

Both come from [anomalyco/opencode](https://github.com/anomalyco/opencode) (formerly `sst/opencode`) at commit `9b4882db54627f2656a6990daafa412f9f3c7c82` (2026-09-30), retrieved on 2026-09-30. That directory is the brand kit that <https://opencode.ai/brand> is built from. Each square 300 × 300 SVG was rendered to 128 × 128 with sharp 0.35.3 (libvips 8.18.3, librsvg 2.62.90), keeping its transparent background, with no other change. The repository is MIT-licensed; the mark belongs to the OpenCode project (Anomaly) and is used here only to identify OpenCode.
