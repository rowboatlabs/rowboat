# Agent37 logo

- `logo.png`: the Agent37 mark in black, for light themes
- `logo-dark.png`: the same mark in white, for dark themes

Both come from `https://www.agent37.com/192.png`, the 192 × 192 mark the Agent37 site shows beside its name, downloaded on 2026-10-01. It is a single-colour mark (black on transparent); Agent37 publishes no brand kit or dark variant, so `logo-dark.png` is the same alpha mask filled white. Each was scaled to 128 × 128 with Pillow (Lanczos), with no other change. The mark belongs to Agent37 and is used here only to identify Agent37.
